# wechat-article-workflow

一个面向 AI Agent（Qoder / Claude Code 等）的 Skill：调研并撰写微信公众号短图文与长文章，制作统一视觉规范的配图，并将成稿保存到公众号草稿箱。

## 包含内容

- **事实核查**：区分官方说明、网友体验与实测边界，不编造结论；免费额度逐项核实（金额、资格、地区、有效期、重置时间等）
- **内容规格**：默认短图文（贴图，标题 ≤20 字，正文 600–900 字）；按需长文（文章，标题 ≤30 字，正文 2000–3500 字）
- **统一视觉规范**：固定奶油底 + 深绿字 + 青绿点缀配色，5 张 2160×2880 信息卡（封面 1 + 卡片 4），版式与命名规则统一
- **权限与验收**：默认只存草稿不发表；手动保存后必须重开草稿逐项核验

## 使用方式

将 `SKILL.md` 放入你的 skills 目录即可，例如：

```text
~/.qoder/skills/wechat-article-workflow/SKILL.md
~/.claude/skills/wechat-article-workflow/SKILL.md
```

之后在会话中提出「调研并写一篇公众号短图文」「制作配图并保存到草稿箱」等需求时，Agent 会自动加载该 skill。

## 适用场景

- AI 工具、Agent、云电脑、免费额度等实用类选题的公众号内容制作
- 需要事实核查与来源记录的观点类内容
- 需要统一视觉风格的信息卡配图生产
- 通过浏览器界面完成公众号草稿的保存与验收
